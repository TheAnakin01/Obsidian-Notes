# How to use this vault (Obsidian in 2 minutes)

Back to [[Meal Planner Home]]

Obsidian is a notes app where notes **link to each other** like a personal Wikipedia. Everything is plain text files
on your computer (`Documents\Obsidian Vault`).

| Want to… | Do this |
|---|---|
| Go to the project start page | Open **Meal Planner Home** — it's ⭐ bookmarked (left sidebar → Bookmarks) |
| Follow a link | Click any purple link (like [[Meal Planner Home]]). Ctrl + click opens it in a new tab |
| Peek at a note | Hover over a link while holding **Ctrl** |
| See how everything connects | Left ribbon → **Graph view** (bugs, decisions and features appear as a web) |
| See what links *to* this note | Right sidebar → **Backlinks** |
| Search everything | **Ctrl + Shift + F** |
| Jump to any note | **Ctrl + O** and type part of the name |
| See bugs/decisions as a table | Open **Project Tracker** — switch views at the top (Bugs, Open bugs, Critical & high, Decisions) |
| See the system as a picture | Open **Meal Planner Architecture** (a Canvas — drag, zoom, rearrange) |
| Filter by topic | Left sidebar → **Tags** (e.g. `#bug`, `#decision`, `#safety`) |
| Add a new bug or decision | New note → **Ctrl + P** → "Templates: Insert template" → *Bug* or *Decision* |
| Write a daily note | Left ribbon → calendar icon (Daily notes) |

## How the notes are organised
- **Overview/** — what the app is and how it works
- **Bugs/** — every problem, with symptom → cause → fix → lesson
- **Decisions/** — why things were built this way
- **Guides/** — how to update and maintain the app
- **Roadmap**, **Build Log**, **Prompts Log** — the history
- The small block at the top of each note (type, status, severity…) is **Properties** — the tracker table reads them.

## Keeping it up to date
After each new change, ask Claude: *"update my Obsidian vault with today's changes"*.
