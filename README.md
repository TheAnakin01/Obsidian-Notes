# Obsidian Notes

Private backup of my Obsidian vault (plain Markdown notes — open the folder in [Obsidian](https://obsidian.md)).

## What's inside
- **Meal Planner/** — everything about my Meal Planner app: features, architecture, 25 bugs with fixes and lessons,
  10 design decisions, roadmap, build log and guides. Start at `Meal Planner/Meal Planner Home.md`.
  Live app: https://meal-planner-pied-beta.vercel.app · code: https://github.com/TheAnakin01/meal-planner
- **AI.md** — log of my AI prompts and results.
- **Templates/** — Bug and Decision note templates.

## How backup works
This folder is a Git repository linked to `github.com/TheAnakin01/obsidian-notes` (private).
Changes are uploaded with commit + push (or automatically with the Obsidian Git plugin).

> Never put passwords or API keys in these notes.
